# Task 10

parking.model contains Vehicle subclasses, Chargeable, Slot and ParkingTicket; parking.pass contains Pass and MonthlyPass; parking.pricing contains PricingRule and StandardPricing; parking.service contains ParkingFacility; parking.app contains Main. Packages match source directory names. javac --release 17 -d build compiles all shared sources, and java -cp build parking.app.Main runs the app. Each task is compiled separately to avoid default-package class-name conflicts in the given exercises.

All model fields are private. Identity, configuration and ticket fields are final. Public getters expose scalar/immutable values; no public getter exposes the live active array or slots array. protected Vehicle constructor and ratePerHour() support subclass specialization without advertising rate mutation. Public enter()/exit() define facility operations. private find() is an implementation detail. The short example constructors in the supplied FeeDemo have package access as given; production constructors are public for access from parking.app. Demonstration trace classes are package-private because they are used only in Task06.

There is no arbitrary setRegNo()/setEntry() because changing identity or entry after admission would break billing and map/set semantics. Mutable state changes use validated domain setters: Slot.occupy(v) rejects null and occupied slots; release() rejects an already-free slot through false. The constructor rejects negative floor/number; isValidSlot() checks actual floor bounds. Vehicle rejects negative duration; charging validates kWh; the factory rejects unknown types. A validating setter is appropriate only when the field is legitimately mutable; immutability is stronger for identity. Invalid exit operations are checked before release/collection updates.

Task10 demonstrates Integer autoboxing/value comparison. Collections such as Map<Integer,...> would box int indexes; arrays use primitive int indexes directly. Integer == compares identity, so cached small values can misleadingly appear equal while larger values do not. Use equals() or unbox non-null values. Unboxing null throws NullPointerException; wrappers also introduce allocation/reference overhead. Task11's benchmark uses String keys and ParkingTicket values without needless boxing.

Alternative: public slot.vehicle permits callers to overwrite an occupied slot and public entry permits a caller to rewrite billing time. Every caller must repeat identical checks. A scalar range/negative check is O(1) per update; registration validation is O(L), bounded here by 15 characters. With m mutation sites, public-state validation must be maintained in O(m) places, compared with one controlled mutator/constructor. Overall p scalar updates still cost O(p) either way, but public fields cannot guarantee every call site validates. Public exposure of an array similarly bypasses business rules even if the array reference is final.
