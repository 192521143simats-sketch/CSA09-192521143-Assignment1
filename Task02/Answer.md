# Task 2

Slot and floor numbers use int because they are array indexes. Registration uses String to preserve letters and leading zeroes. Entry and exit use LocalDateTime to retain dates across midnight. Duration uses Duration and long minutes. The integrated model uses long whole rupees because every configured rate is integral; multiplication/addition use exact arithmetic where totals could overflow. A currency with fractional rupees would need long paise or BigDecimal. The supplied Task08 exercise retains double exactly as requested.

Slot[][] is a jagged array: slots[f] = new Slot[capacities[f]]. For {20,50,100}, rows have those lengths, so no position exists beyond its floor capacity. Each Slot contains floor, number, charging flag and a private Vehicle reference. Direct access with validated floor/slot indexes takes O(1); scanning for a suitable free position takes O(N), N = sum of capacities.

The application reads optional command-line arguments: java -cp build parking.app.Main CAR TN01A1. Demonstrations use fixed timestamps for repeatable tests. This avoids Scanner token/newline issues. Arguments are validated by the factory and constructors. kWh uses int, with an explicit widening multiplication 12L * kWh. Duration is rounded upward to a minute before integer hours are rounded upward. For 61 minutes, 61 / 60 is 1 and wrongly bills Rs 30; (int)(61 / 60.0) also truncates to 1. hours = minutes / 60 + (minutes % 60 == 0 ? 0 : 1) yields 2 and Rs 60. It also avoids overflow from minutes + 59. A one-nanosecond stay is positive and bills one hour. Date-aware overloads avoid LocalTime's ambiguity across midnight.

Alternative representations: a rectangular one-dimensional array can use index = floor * slotsPerFloor + slot only when every floor has the same capacity. With uneven floors, either allocate F * maxCapacity cells (wasting cells and requiring validity checks), or build a prefix-offset array where index = offsets[floor] + slot. Known floor/slot lookup is O(1) with prefix offsets, using O(N+F) space and O(F) setup. Recovering a floor from a flat index is O(F) by linear offsets or O(log F) by binary search. Jagged arrays use O(N+F) space and O(1) known-coordinate access. ArrayList<String[]> also uses O(N+F) space, O(1) get(floor)[slot], and supports amortized O(1) appending of a row; each row still has fixed length. Every representation takes O(N) worst-case allocation by scanning. Strings store only occupant identity; the integrated Slot objects additionally carry suitability and controlled occupancy.
